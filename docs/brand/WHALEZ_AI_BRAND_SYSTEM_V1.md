# Whalez-AI Brand System V1

## Master identity
Whalez-AI is the single intelligence and single public AI identity of the Whalez-AI Ecosystem.
Models, agents, sub-agents and specialized runtimes are implementation mechanisms or delegated capabilities. They are not separate public AIs.

## Naming
Use: Whalez-AI
For a specialized function: Whalez-AI · <Capability>
Examples: Whalez-AI · Intelligence Core; Whalez-AI · Execution; Whalez-AI · Security & Integrity; Whalez-AI · Governance & Compliance; Whalez-AI · Chain History.
Model/provider names are implementation detail unless disclosure is required.

## Product hierarchy
Whalez-AI Ecosystem — umbrella/company intelligence identity.
WhalezChain — native state, provenance and finality rail.
DeltaAlpha-TradePro — public financial operating platform.
WHZ / PTN / PRN — native asset identities within WhalezChain.

## AI integration rule
Every model or agent receives an internal capability ID and delegated authority scope, but the public identity remains Whalez-AI.
The identity layer is separate from the model layer:
Whalez-AI identity → capability → policy/authority → model/runtime implementation
This allows multiple models to be routed for different tasks without creating a fragmented brand or pretending that each model is a separate intelligence.

## Authority
Capability specialization does not create sovereign authority.
Execution-capable Whalez-AI functions operate only within existing Founder Authority, policy, approval, eligibility, security and settlement controls.

## Asset branding
WHZ, PTN and PRN use distinct marks so users can distinguish native assets, while their shared geometry establishes a common WhalezChain family.
No asset mark is evidence of external custody, liquidity, legal status, reserve backing or mainnet finality by itself.
